# calculadora_simple
Calculadora simple de 5 operaciones aritméticas: suma, resta, multiplicación, división y porcentajes («como tal es multiplicar y dividir sin paréntesis»). Asimismo, tiene interfaz gráfica (front-end) y se puede usar en consola. Por ende, tiene personalización sencilla con imagenes (skin Kuromi por predeterminado) y, sólo está para Windows.
